# 양육관 8문항 — 초안

> `TECH_LOGIC.md §3.4`의 소프트 점수 `V`(가중치 0.35)를 만드는 설문.
> 평가 설계는 [AI_MATCHING_EVAL.md](AI_MATCHING_EVAL.md) `E2`.
>
> **바움린드(Baumrind)의 온기(반응성)·통제(요구성) 2축을 각 4문항으로 구성한다.** 바움린드가 8개 원칙을 제시한 것이 아니다 — 8문항은 우리 조작화다.

---

## 1. 설계 원칙 — 왜 이렇게 만들었나

**① 양쪽 답이 모두 그럴듯해야 한다.** 이 설문의 최대 위험은 오답이 아니라 **분산 소실**이다. "아이의 감정을 잘 받아주시나요?"는 전원이 4~5점을 찍는다(사회적 바람직성 편향). 모든 쌍의 유사도가 0.9대에 몰리면 `V`는 변별력이 없고 **랭킹의 35%가 사실상 상수**가 된다.

→ 리커트 동의 척도를 쓰지 않는다. **양극 5점**으로 양 끝에 서로 다른 **정당한** 행동을 배치하고, 가운데를 "상황에 따라"로 둔다. 어느 쪽을 골라도 좋은 부모다.

**② 추상적 신념이 아니라 구체적 장면을 묻는다.** "훈육을 중시한다"는 답하기 쉽고 예측력이 없다. 실제로 돌봄 위탁에서 부딪히는 지점 — 영상 시청, 간식, 다칠 것 같을 때, 울 때 — 을 묻는다.

**③ 역채점 문항을 섞는다.** 축마다 1개씩 방향을 뒤집어, 문항을 안 읽고 한쪽으로만 찍는 응답(묵종 편향)을 걸러낸다.

**④ 8문항을 넘기지 않는다.** 교대근무자가 가입 중에 답한다. 이탈이 정확도보다 비싸다.

## 2. 문항

응답: **1 ─ 2 ─ 3 ─ 4 ─ 5** (1=왼쪽에 가까움, 3=상황에 따라, 5=오른쪽에 가까움)

### 온기 축 (반응성) — 아이의 정서 신호에 얼마나 직접·즉각 반응하는가

| # | 코드 | 장면 | 왼쪽 (1) | 오른쪽 (5) |
|---|---|---|---|---|
| 1 | `W_EMOTION` | 아이가 떼를 쓰며 울 때 | 왜 속상한지 먼저 말로 받아준다 | 진정될 때까지 조용히 기다린다 |
| 2 | `W_RESPONSE` | 놀아달라고 계속 부를 때 | 하던 일을 멈추고 간다 | 하던 일을 마치고 간다 |
| 3 | `W_AFFECTION` | 평소 애정 표현 | 자주 안아주고 무릎에 앉힌다 | 필요할 때 가볍게 다독인다 |
| 4 | `W_REASON` ↺ | 안 된다고 말할 때 | 지금은 안 된다고 짧게 말한다 | 왜 안 되는지 이유를 설명한다 |

### 통제 축 (요구성) — 규칙을 얼마나 명시적·일관되게 요구하는가

| # | 코드 | 장면 | 왼쪽 (1) | 오른쪽 (5) |
|---|---|---|---|---|
| 5 | `C_SCREEN` | 영상·게임 시간 | 정해둔 시간만 허용한다 | 그날 상황에 맞춰 조절한다 |
| 6 | `C_SNACK` | 간식 | 정해진 것만 정해진 때에 | 원하면 웬만큼 들어준다 |
| 7 | `C_DISCIPLINE` | 잘못했을 때 | 그 자리에서 바로 짚어준다 | 스스로 알아챌 때까지 둔다 |
| 8 | `C_SAFETY` ↺ | 다칠 것 같은 놀이 | 조금 위험해도 해보게 둔다 | 다치기 전에 미리 막는다 |

`↺` = **역채점**. 4번과 8번은 오른쪽이 높은 값이 되도록 뒤집어 채점한다.

## 3. 채점과 벡터화

```python
REVERSED = {"W_REASON", "C_SAFETY"}          # 오른쪽이 축의 '높음'인 문항

def to_vector(answers: dict[str, int]) -> list[float]:
    """1~5 응답을 -2~+2로 중심화한다. 역채점 문항은 부호를 뒤집는다."""
    out = []
    for code in ITEM_ORDER:                   # W_EMOTION ... C_SAFETY (8개 고정 순서)
        v = answers[code] - 3                  # 3(상황에 따라) = 0
        out.append(-v if code in REVERSED else v)
    return out
```

**중심화가 핵심이다.** 1~5를 그대로 쓰면 모든 벡터가 양의 영역에 몰려 **코사인이 구조적으로 0.9 근처**가 된다. `-2~+2`로 옮겨야 유사도가 음수까지 벌어지고, 그래야 순위가 생긴다.

```python
def value_similarity(a: list[float], b: list[float]) -> float:
    """코사인을 0~1로 사상해 S의 V 항에 넣는다."""
    na, nb = norm(a), norm(b)
    if na < 1e-9 or nb < 1e-9:
        return 0.5                             # 전부 '상황에 따라' — 중립 처리
    return (dot(a, b) / (na * nb) + 1) / 2      # [-1,1] → [0,1]
```

**영벡터 가드가 필요하다.** 8문항 전부를 3으로 찍으면 노름이 0이라 코사인이 정의되지 않는다. 이때는 `V = 0.5`로 두고, 가입 UI에서 *"모두 '상황에 따라'로 답하면 추천 정확도가 떨어집니다"* 를 안내한다. 응답을 강제하지는 않는다.

**`S`의 다른 항과 스케일을 맞춘다.** `S = 0.35·V + ...`의 가중치는 각 항이 `0~1`임을 전제한다. 코사인 원값(`-1~1`)을 그대로 넣으면 안 된다.

## 4. 파일럿 전에 확인할 것

| 점검 | 방법 | 기준 |
|---|---|---|
| **분산이 살아 있는가** | 사전 응답 30명 수집 후 쌍별 유사도 분포 | 표준편차 **0.15 이상**. 미달이면 몰린 문항을 교체 |
| **축이 실제로 두 개인가** | 8문항 상관행렬 · 주성분 2개 | 축 내부 상관 > 축 간 상관 |
| 축 내적 일관성 | 축별 Cronbach α | 0.6 이상(4문항이라 높게 안 나온다 — 낮으면 문항 교체) |
| 묵종 편향 | 역채점 문항(4·8)과 같은 축 문항의 상관 | 뒤집어 채점한 뒤 양의 상관이어야 정상 |

**분산 점검을 통과하지 못하면 문항을 고친다.** 8문항 구조가 아니라 **개별 문항이 원인**이므로, 몰린 문항만 더 대립적인 장면으로 교체한다.
