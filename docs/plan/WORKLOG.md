### 오늘 정한 것 (되돌리려면 근거를 다시 봐야 하는 것들)

**포인트·돈**
- **포인트는 시간화폐가 아니다** (권장, 최종 확정은 미결 → Q-0). 1시간=1P로 하면 최저임금법·4대보험·일용직 신고 의무가 발생한다는 게 부분유료화 문서의 근거. 별첨 스키마도 이미 포인트와 `give_hours`를 분리해 놨다
- **노쇼방지금 2만원 현금 예치 → 포인트 에스크로로 변경.** 현금은 PG·전자금융업 등록 이슈로 Phase 2
- **월 구독료 1,990원 확정** (기술로직 2,990 vs 부분유료화 990의 중간)
- **구독은 포인트를 주지 않는다.** 현금→포인트 경로가 열리면 포인트가 사실상 화폐가 된다

**매칭**
- 필수 태그 사전을 **30개 → 10개**로 축소 (`SAFETY` 4 + `CAPABILITY` 6). 스키마가 이미 계산하는 것(야간 가용·연령 수용·거리)은 태그로 만들지 않는다는 기준
- **알레르기 태그는 조건 완화 금지** — UI에서 해제 자체가 막혀야 함
- 랭킹 `S = 0.35V + 0.25M + 0.20R + 0.20B` (별첨 확정안 채택)
- 야간(22~06시) **인원 상한 1:5는 랭킹 감점이 아니라 배제 필터**

**신뢰·평가**
- **신뢰 등급은 사용자 속성이 아니라 관계(edge) 속성.** 프로필 컬럼으로 두면 "A와 3번 만난 사람이 처음 보는 B에게도 단독위탁 가능"이 되어 안전장치가 무너짐
- **돌봄마음** — 별점 0~5를 색으로. 프로필 상시 노출 안 하고 **리뷰 열람 시에만** 보임
- 주의: `평점 4.0`이 L3(단독위탁) 승급 조건이라 **표시 규칙을 바꾸면 승급 조건도 흔들린다**

**반경 유료화**
- 3단계 사다리: `R0` 800m~1km(무료) → `R1` 2km → `R2` 인접 행정동
- 비대칭 문제(유료자는 무료자를 보는데 반대는 안 보임) → **발신자 반경 기준 + 수신자에게 거리 구간 명시**. 정확 거리는 삼각측량 위험이라 `WALK/NEAR/ADJACENT` 구간만 노출
- 알림은 푸시·목록·상세·**수락 확인 모달 4곳 모두**에 표시

**가설 (오늘 가장 크게 바뀐 것)**
- 처음엔 "근무표 50장 모아서 상보성 확인"이었는데 **근무표는 구할 수 없는 자료**(동료 정보가 담긴 내부 문서)라 폐기
- 합성 데이터로 대체하면 동어반복 — 3교대 규칙으로 만든 패턴이 엇갈리는 건 당연
- → **H1-a를 "공공데이터로 지역별 교대근무 밀도를 추정한다"로 전환.** 진짜 모르는 건 패턴이 아니라 **사람 수**

### 2026-08-07 추가 — H1-a v2 개정

- 공공데이터 3종(회원현황·돌보미현황·서비스제공기관) **실제 수집 완료**. 2020-01~2026-02, 74개월, 기관 232곳
- H1-a는 원래 `밀도 그리고 미충족수요` 두 절의 결합이었다. **㈏ 미충족수요는 닫혔고 ㈎ 밀도는 남았다**
- ㈏를 재서술: "대기가 있다" → **"인력 총량 부족으로 설명되지 않는다"**. 가용 돌보미 18,722명이 있는데도 대기가 42번 중 41번 늘었다
- **주의: 대기(가구)와 돌보미(사람)는 단위가 다르다.** 27,519÷18,722=0.68을 "인력 부족"으로 읽으면 반박당한다. 실제 1인당 담당은 13.3가구
- **가설 번호를 늘리지 않는다.** 이 개정을 `H1-b`로 부르지 않고 **H1-a (v2)** 로 통일 — 번호가 늘면 "가설 1개" 원칙이 흔들려 보인다
- 남은 블로커: 어린이집 정보(15013108) 승인. 안 나오면 서비스제공기관 좌표 232곳으로 대리 추정(정밀도 하락을 리포트에 명시)
- 파싱 평가도 3계층으로: L1 합성(회귀 테스트용) / L2 마스킹 실물 3~5장(과대평가 보정) / **L3 사용자 확정본(진짜 지표)**. 검증 게이트에서 사용자가 고친 셀이 곧 정답이라 별도 라벨링이 필요 없다
