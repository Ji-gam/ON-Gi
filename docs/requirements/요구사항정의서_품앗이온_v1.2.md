# 1. 문서 개요
## 1.1 목적
본 문서는 품앗이온(ON) 서비스의 5주 MVP 개발 범위에 포함되는 기능·비기능 요구사항을 정의한다. 기획서에서 제시한 가설 검증 구조(1단계 기술가설 → 2단계 서비스가설 → 3단계 비즈니스가설) 중 1단계 기술가설과 2단계 서비스가설의 진입부를 실증하는 데 필요한 최소 요구사항을 확정하는 것을 목적으로 한다. 본 문서에서 확정한 요구사항 ID(REQ-)는 화면 설계서의 화면 ID(SCR-) 및 기능 목록표의 기능 ID(FN-)와 상호 참조되어 추적성을 보장한다. v1.2는 최종 기획서(예선심사과제 제출본)를 기준으로 전면 대조해 갱신한 판이며, 주요 반영 사항은 ① H1-a 밀도 가설 채택 확정과 그 한계·후속 검증 계획, ② 매칭 점수 배분(가치관·상보시간 동일 비중) 확정, ③ 분쟁 A/B/C 3단계 처리 절차, ④ 2단계 신뢰 점수(규칙 기반 → 앙상블) 전환 대비 로그 적재, ⑤ 구독(월 1,990원) 기반 수익 모델의 전환 의사 측정, ⑥ 성장 시나리오(Day1 30명 → 800명, 10개월차 흑자 전환) 반영이다.

## 1.4 용어 정의
| 용어 | 정의 |
| --- | --- |
| 상보(相補) 시간 | 두 가정의 근무 시간이 서로 엇갈려, 한쪽이 근무 중일 때 다른 쪽이 아이를 맡아줄 수 있는 시간 구간. |
| 48슬롯 비트마스크 | 하루 24시간을 30분 단위 48칸으로 나누어 돌봄 가능(1)/불가(0)로 표현한 자료구조. 두 사용자의 마스크에 AND 연산을 적용해 상보 구간을 산출한다. |
| 하드 필터(Stage 1) | 충족하지 못하면 후보에서 즉시 제외되는 조건. H3 반경 1km와 필수 태그 10개(알레르기 대응·투약 관리·응급처치 이수·비흡연 가정 등 완화 불가 4종 포함)로 구성된다. |
| 소프트 점수(Stage 2) | 바움린드 8차원 벡터의 코사인 유사도 등 정도(degree)로 평가되는 항목. 매칭 총점의 35%를 양육 가치관 유사도가 차지한다. |
| 바움린드 8차원 | 발달심리학의 Baumrind 양육유형 이론에 기반해 온기(반응성) 4문항 + 통제(요구성) 4문항으로 구성한 진단 문항 및 그 결과 벡터. |
| 신뢰 등급 L1/L2/L3 | L1: 매칭 성립·대화 가능. L2: 공개 장소 공동육아 진행 중. L3: 단독 위탁 해금(아이를 혼자 맡길 수 있는 상태). |
| 포인트 원장 | 돌봄 시간을 교환 단위로 기록하는 복식부기 장부. 모든 거래는 차변·대변 합이 항상 0이 되도록 기록한다. |
| Pod | 신뢰가 형성된 4~6가구 또는 동일 직장 단위로 묶인 상시 상호돌봄 그룹. MVP에서는 데이터 모델만 준비하고 UI는 P1에서 구현한다. |
| H3 인덱스 | Uber H3 육각 격자 기반 지리 인덱스. 정확한 주소 대신 격자 셀 단위로 위치를 다뤄 개인정보 노출을 줄인다. |
| 상보 스코어 | 두 사용자의 48슬롯 마스크 AND 결과로 산출한 시간 축 점수. 가치관 유사도와 분리 계산해 매칭 총점에 동일 비중으로 반영한다. |
| 분쟁 A/B/C 단계 | A=당사자 간 자율 조정, B=챗봇(RAG)이 돌봄 일지·체크인 기록을 근거로 쟁점을 정리, C=운영자 최종 판정. MVP에서 확정 판정 권한은 C단계에만 있다. |
| 2단계 신뢰 점수 | 1단계는 사람이 정한 가중치의 규칙 기반 합산, 2단계는 정성 신호 모델과 행동 로그 모델을 결합한 앙상블. 데이터 부족에 따른 과적합을 피하기 위한 단계 설계로, MVP는 1단계만 운영하고 2단계 학습 데이터를 적재한다. |
| 밀도 임계점 | 무작위 3교대 근무표 시뮬레이션에서 상보 상대를 만날 확률이 60%를 넘는 최소 그룹 크기. 실험 결과 35명으로 확인되었으며 상보 후보 보유율 목표 60%의 산출 근거다. |

| REQ-F-ACC-11 | 제재 이력 보존형 탈퇴 | 탈퇴 시 개인정보와 아동 정보는 파기하되, 이용 제한·신고 확정 이력은 본인확인 값의 단방향 해시로만 보존해 재가입 시 대조한다. 보존 항목과 기간은 개인정보 처리방침에 고지한다. | 중요 | 제재 이력이 있는 계정으로 탈퇴 후 동일 본인확인 정보로 재가입하면 가입이 차단된다. |

## 2.2 근무표·시간 (SCH)
| 요구사항 ID | 요구사항명 | 상세 내용 | 우선순위 | 검증 기준 |

| 검증 상태 | 1단계 기술가설의 하위 가설 H1-a(공공데이터로 교대근무자 밀도 확인)는 채택되었다. 아주대·성빈센트 등 대표 5개 병원 반경 1km 존에서 어린이집 101개·정원 4,882명, 교대제 비중 24.2%를 적용해 약 1,182가구를 추정했고, 무작위 3교대 시뮬레이션의 밀도 임계점 35명을 충분히 상회했다. 다만 정원이라는 지역 집계 데이터로 개별 가구의 거주·이용 행동을 추론한 것은 생태학적 오류(MAUP)에 해당하고, 직장과 거주지가 분리된 경우를 반영하지 못한다. 후속 검증으로 ① 동일 방법을 여러 행정동에 적용한 민감도 비교, ② 통계청 생활이동데이터 또는 국토교통부 가구통행실태조사(OD)를 이용한 실제 통근지 대조를 수행한다. 실측 상보 후보 보유율이 60%에 미달할 경우 REQ-F-MAT 계열의 가중치 정책과 반경·개월 수 범위를 재검토한다. |
| 가정 | ① 동일 지역 교대근무자 사이에는 통계적으로 유의한 상보 시간이 존재한다. ② 후보가 제시되면 사용자는 최소 1회 이상 공동육아를 시도한다. ③ 시범 대상은 근무표를 이미 공유하는 병원 단위 집단이므로 초기 밀도 확보가 가능하다. |
| 리스크 | 상보 후보 부족(대응: 반경·개월 수 범위 완화 실험, 대기 등록) / 신뢰 단계 이탈(대응: 동반 돌봄 전용 피벗) / LLM 응답 지연(대응: 규칙 기반 문장 폴백) / 신뢰 점수 앙상블의 데이터 부족 과적합(대응: MVP는 규칙 기반만 운영, 학습 데이터만 적재) / 구독 전환율 미검증(대응: 실결제 없이 전환 의사 이벤트로 선측정) |
| 문서 정합성 | 최종 기획서와 대조한 결과는 다음과 같다. ① OCR — 기획서 1-4의 기술 나열에는 남아 있으나 <표3> 주요 기능과 MVP 범위에는 포함되지 않으므로, 본 문서에서 P1으로 확정한다. ② 매칭 점수 배분 — 기획서 2장의 "가치관 35%"와 3-2의 "절반씩 반영"은 가치관 35% : 상보 시간 35%의 동일 비중으로 해석해 REQ-F-MAT-04/05에 확정 반영했다. ③ 밀도 실험 — v1.1에서 지적한 "1,1182가구" 표기 오류는 최종 기획서에서 1,182가구로 수정되었으나, ⑥항의 "1,182명" 표기는 가구 단위와 혼용되어 있어 기획서 측 단위 통일이 필요하다. ④ 비용 — 기획서의 AWS 크레딧 130만 원(2년) 기준에 맞춰 REQ-NF-OPS-01의 월 비용 상한을 15만 원에서 5만 원으로 하향 조정했다. |
